# STEVEN VERSE - Projeto Individual
<br>

**O QUE É O PROJETO?**
<br><br>
O projeto Steven Verse surge a partir de um problema principal, a falta de um espaço para interação entre os fãs da série, que muitas vezes expressam suas opiniões e atualizações quanto a obra em locais distintos, trazendo uma dispersão maior do fandom². Isso faz com que o público de Steven Universo tenha uma dificuldade maior em encontrar informações sobre atualizações do desenho, curiosidades sobre os personagens e uma base de informações confiáveis em conjunto com a interação do próprio público. 

A partir dessa dor foi criada a ideia do Steven Verse, um site que une os dois pontos fortes da obra, o universo e o público. A ideia principal é o desenvolvimento de um site onde o usuário pode ver dados personalizados sobre ele e as principais informações sobre a obra, como as músicas, episódios marcantes, personagens e suas histórias, principais sagas, entre outros, porém junto a isso, um fórum onde o público possa interagir e expor suas opiniões sobre a obra, se atualizarem, discutirem e principalmente aproveitarem do ambiente virtual como uma extensão do mundo que muitos já fizeram parte, um dia, pela tela da televisão.

# ACESSO ao Projeto
<br><br>

**Iniciar:**
    <br>
- Para começar clone o respositório em sua máquina
- Atravéz do terminal entre na pasta web-data-viz com o comando `cd web-dataviz main`
- Após clonar, instale as bibliotecas necessárias com `npm i`
- Para iniciar e rodar o site `npm start`
- Agora é só ir ao seu navegador e acessar o link http://localhost:3333/index.html
